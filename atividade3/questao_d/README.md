# Questão (d) — Sequência rítmica

**A implementar.** Esta pasta ainda não contém firmware compilável.

Conforme o [enunciado](../../Enunciado.pdf), o usuário deve reproduzir uma
sequência rítmica com o botão USER. Começar com três segmentos de intervalos
curtos ou longos e acrescentar um segmento a cada sequência correta.

Cada pressionamento usa EXTI; SysTick mede os intervalos entre cliques.
A serial apresenta os intervalos medidos, sua classificação e o resultado
correto ou incorreto.

Os fontes, testes e documentação ficarão aqui, usando a plataforma compartilhada.
